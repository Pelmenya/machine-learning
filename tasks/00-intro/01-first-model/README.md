# 00-intro / 01 — Первая модель: цикл из 6 этапов

Проходим полный цикл ML-задачи от данных до метрики на учебном датасете.
Классический стартовый кейс: предсказать бинарный исход по набору признаков.

## Цель
Своими руками собрать классификатор и пройти все 6 этапов любой ML-задачи:

1. **Подготовка данных** — выделить признаки `X` и целевую переменную `y`.
2. **Деление на train/test** — часть данных для обучения, часть для проверки.
3. **Выбор и создание модели** — выбрать алгоритм, создать объект модели.
4. **Обучение** — `model.fit(X_train, y_train)`.
5. **Предсказание** — `model.predict(X_test)`.
6. **Оценка качества** — сравнить предсказания с правильными ответами (метрика).
