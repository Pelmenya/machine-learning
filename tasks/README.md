# tasks/ — задания по программе

Каждый блок программы (`ML-инженер_программа.md`) = свой каталог:

| Каталог | Блок программы |
|---|---|
| `00-intro/` | Старт: цикл ML-задачи из 6 этапов на простом кейсе |
| `01-sql/` | Анализ данных с помощью SQL |
| `02-python-eda/` | Анализ данных с помощью Python (pandas, EDA, ООП) |
| `03-classic-ml/` | Классические алгоритмы ML |
| `04-advanced-ml-nn/` | Продвинутый ML + нейросети (PyTorch, RNN, трансформеры) |
| `05-mlops/` | Автоматизация и внедрение (pipelines, FastAPI, Docker, A/B) |

## Соглашение по одному заданию

Каждое задание — отдельный подкаталог `NN-короткое-имя/` (NN = порядковый номер):

```
tasks/03-classic-ml/02-first-model/
├── README.md      # условие + критерии готовности (что считаем "сделано")
├── solution.py    # решение (или solution.ipynb для исследований)
└── notes.md       # вывод: что понял, на чём споткнулся, урок из пробы
```

**Принцип:** быстрая петля гипотеза → дешёвый тест → урок. Сначала код,
теория подтягивается по ходу и фиксируется в `notes.md`.
