# ml-base

Учебный репозиторий для освоения машинного обучения с нуля.

## О проекте
- Цель: изучить ML по собственной траектории на базе программы курса
  «ML-инженер» Яндекс Практикума (полная карта — `ML-инженер_программа.md`).
- Формат: учимся на бесплатных материалах, Claude — ментор (даёт задачи,
  проверяет код, объясняет по ходу). Прикладной подход: быстрая петля
  гипотеза → дешёвый тест → урок, теория приходит из проб.
- Стек: Python (numpy, pandas, scikit-learn, matplotlib), далее PyTorch и MLOps.

## Структура репозитория
```
ml-base/
├── ML-инженер_программа.md   # полная карта программы (источник истины)
├── requirements.txt          # зависимости (lock — после pip freeze)
├── tasks/                    # задания по блокам программы (см. tasks/README.md)
│   ├── 00-intro/  01-sql/  02-python-eda/
│   ├── 03-classic-ml/  04-advanced-ml-nn/  05-mlops/
├── src/mlbase/               # переиспользуемый код (утилиты, общие хелперы)
├── notebooks/                # черновики и эксперименты (Jupyter)
├── data/                     # датасеты (raw/ — в .gitignore)
├── docs/                     # syllabus (PDF+картинки), скриншоты, конспекты
├── scripts/                  # вспомогательные скрипты (рендер PDF и т.п.)
└── .claude/                  # хуки, settings, state/HANDOFF.md
```

**Соглашение по заданиям** (детали — `tasks/README.md`): одно задание =
подкаталог `tasks/<блок>/NN-имя/` с тремя файлами: `README.md` (условие +
критерии готовности), `solution.py`/`.ipynb` (решение), `notes.md` (вывод/урок).
Чистота репо: новый код и данные кладём по структуре, корень не засоряем.

## Окружение
- Windows. Python-окружение — `.venv` (создавать `python -m venv .venv`,
  ставить из `requirements.txt`). Интерпретатор: `./.venv/Scripts/python.exe`.
- Node-хуки в `.claude/hooks/` запускаются автоматически (кроссплатформенно).

## Session handoff
Перед завершением крупной задачи или когда пользователь говорит, что
заканчивает, обновляй `.claude/state/HANDOFF.md`: текущая задача, принятые
решения, следующие шаги, открытые вопросы. Перезаписывай файл целиком, не
накапливай историю. Максимум 50 строк.
