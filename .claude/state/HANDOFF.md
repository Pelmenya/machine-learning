# HANDOFF — состояние проекта ml-base

_Обновлено: 2026-06-13_

## Текущая задача
Освоение ML с нуля по собственной траектории. За основу взята программа
курса «ML-инженер» Яндекс Практикума (полная карта — `ML-инженер_программа.md`),
учимся на бесплатных материалах + практика руками в этом репо.

## Принятые решения
- Целевой ориентир — курс «ML-инженер» (а НЕ Data Science): полнее —
  классический ML + DL + MLOps + LLM/RAG. Отдельный курс DS не нужен.
- Формат: своя траектория на бесплатном, Claude как ментор (задачи + ревью).
  Кейс-подход (цикл из 6 этапов), петлю крутим быстро: код → теория.
- Персистенс контекста между сессиями — через hooks (SessionStart/PreCompact).
- Заведена структура репо (см. CLAUDE.md): `tasks/` по блокам, `src/mlbase/`,
  `notebooks/`, `data/`, `docs/` (syllabus + скриншоты), `scripts/`.
